# childcare-compare-site（仮称：こそだて比較ノート）

子育て家庭向けの商品・サービス比較メディアのプロジェクトフォルダです。
※ サイト名は未定のため「こそだて比較ノート（仮）」を仮置きしています。

## コンセプト

「一番人気の商品を決める」のではなく、
「それぞれの家庭や使い方に合う商品を見つけやすくする」比較メディア。

## フォルダ構成

```
childcare-compare-site/
├─ research/                 # 商品調査・比較表などの調査資料
│  └─ sakunyuki/
│     └─ sakunyuki_research_report_1.md   # 2026-07-20 搾乳機 商品調査レポート
├─ public/                   # Webサイト本体（このフォルダをそのまま公開できる構成）
│  ├─ index.html             # TOPページ
│  ├─ sakunyuki.html         # 搾乳機比較ページ（比較表・タイプ診断・FAQ・出典）
│  ├─ about.html             # 運営方針・編集ポリシー
│  ├─ ads-policy.html        # アフィリエイト広告についての案内
│  ├─ privacy.html           # プライバシーポリシー（暫定版）
│  └─ assets/
│     ├─ css/style.css       # 共通スタイル（レスポンシブ対応）
│     └─ js/
│        ├─ main.js          # モバイルナビ等の共通スクリプト
│        └─ quiz.js          # 搾乳機タイプ診断（5問）
├─ src/                      # 原稿の下書き・部品など（今後使用）
└─ README.md
```

## ブラウザでの確認方法

`public/index.html` をダブルクリックするだけで表示できます（ビルド不要の静的サイト）。

## 運用ルール

- 調査資料は `research/<テーマ名>/` に保存する
- 商品仕様はメーカー公式サイトなどの一次情報を最優先し、確認できない項目は「公式情報で確認できず」と記載する
- 実際に使用していない商品について、実体験を装った表現をしない
- 総合ランキングで「1位」を決めない（タイプ・使い方で整理する)
- アフィリエイトリンクは `sakunyuki.html` 内の `<!-- TODO: アフィリエイトリンク設置箇所 -->` コメント部分に設置予定（現在は仮ボタン）
